# Echo Gallery UI 文案規範

## 產品敘事

Echo Gallery 是個人化內容回流工具。以「安靜的冒險日誌 × 私人的奇珍藏館」為語言基調，讓收藏、探索與已完成的成果有可回望的來歷。系統提供線索與選擇，不以收藏量、完成率或晉級速度評價使用者。

採用繁體中文，語調沉著、內斂、略帶神祕。敘事放在副標、引導與空狀態；操作名稱、資料定義與錯誤保持精確。使用現代中文，不仿寫特定作品台詞。

## 五層文字

| 層級 | 使用位置 | 原則與例子 |
| --- | --- | --- |
| 1 | 導航、按鈕、表單操作 | 短而清楚，通常 2～6 字；保留「今日回流」「新建卡片」「儲存」「取消」「封存」等功能名稱 |
| 2 | 頁面、區塊標題 | 簡潔且能辨認用途，如「尚未落幕的探索」「下一次相遇的間隔」；表單區塊使用具體名稱 |
| 3 | 副標、引導 | 一至兩句，描寫目前情境與未來可能，不寫長篇操作手冊 |
| 4 | 空狀態、成功通知、階段提示 | 可有較強氛圍，但必須明確表達真實狀態或已確認的結果 |
| 5 | 統計定義、錯誤、危險操作 | 精確優先；保留數值、單位、條件、後果與影響範圍 |

## 各功能語彙

| 功能區 | 建議語言 | 邊界 |
| --- | --- | --- |
| 今日回流、卡片 | 歸來、重逢、留下的線索 | 日期、回流天數、暫停、封存與待整理狀態明確顯示 |
| 實驗場 | 探索、試法、發現、材料、土壤、長出新卡 | 保留既有角色與欄位；設定試法不表示已經嘗試，種入卡片不表示已產生成果 |
| 奇珍展覽館 | 入藏、試煉、晉級、收益、來歷 | 奇珍是已完成成果；試煉用目標等級顯示；收益限已發生的新作品、回應或機會，不限金錢收入 |
| 議事廳 | 線索、訊號、判斷、選擇、等待 | 保留系統問題、模型、迴路與介入等既有專門概念 |
| 總覽、近期回顧 | 餘響、積累、新枝、留下的痕跡 | 敘事名稱不改變統計口徑；提供原有定義 |
| 回流狀態、搜尋、篩選 | 低敘事濃度，以資料說明為主 | 不用敘事詞取代查詢條件、狀態或數量 |

「產出」不做全站取代。奇珍記錄已發生收益的按鈕使用「＋記收益」；其他創作成果依原語意保留。「試煉」是奇珍檢定的介面名稱，API、型別與狀態識別字不改。

## 頁面與元件範例

| 情境 | 文案 |
| --- | --- |
| 現在行動副標 | 有些嘗試尚未落幕，有些珍藏仍有餘響。眼前的一切，正等待你的下一個選擇。 |
| 試法尚未設定 | 新的試法尚未寫下。不妨先翻翻收集的材料。 |
| 奇珍無館藏 | 展櫃尚且空著。第一件奇珍，會有什麼來歷？ |
| 試煉等待確認 | 試煉已經展開，結果仍未揭曉。 |
| 試煉未通過 | 這次試煉未能晉級，但經歷已經留下。 |
| 無收益紀錄 | 它已經入藏。至於未來還能帶來什麼，現在尚無答案。 |
| 載入失敗 | 無法載入卡片；提供「重新載入」操作 |
| 刪除收益紀錄 | 刪除這筆收益紀錄？刪除後無法復原；相關卡片仍會保留。 |

## 精確性與實作規則

- 區分現在狀態、未來規劃、已發生事件。API 成功回應之前，不宣稱儲存、入藏、晉級或收益記錄成功；更新既有紀錄不宣稱取得新收益。
- 空館藏、查詢無結果、載入中與載入失敗分別描述。不同試煉狀態的提示互斥；未來階級的預先規劃不冒充目前試煉。
- 統計保留實際數值、單位與解釋。例如「故物重逢」仍指舊卡重新參與，「新枝萌生」指保留來源關係的新卡，「奇珍再現價值」計算有收益紀錄的不同奇珍件數。
- 刪除確認說明不可復原性、將刪除的資料與仍保留的內容；封存、暫停與解除關聯不可描述成刪除本體。
- 表單必填、長度限制、網址格式、日期與錯誤以實際規則為準。Tooltip 解釋條件，不加入旁白。
- 不改動使用者自訂標題、內文、試法、發現、奇珍、檢定名稱或收益紀錄。範例必須標明「例如」並保持通用，不將個人主題寫成固定功能。
- 沿用局部 template 與既有共用文字來源（如 `utils/treasure.ts`、`utils/cardTextFieldCopy.ts`）。只有真正重複且需要一致維護的文字才抽共用常數，不導入額外 i18n 框架。
- Element Plus 使用套件內建繁體中文語系，涵蓋日期、分頁、預設選擇提示與關閉操作。
- 不因改字調整 API key、路徑、Query Key、Enum、Test ID、資料模型、演算法或版型。若顯示字串被用於判斷，先檢查該依賴。
- 長文優先精簡；保留既有設計系統。檢查 1440px、768px、390px、320px 下的換行、截斷、Dialog 捲動、按鈕與 Tooltip。

## 禁止事項

不使用宮廷稱謂、全面文言、成功學口號、大量驚嘆號或 Emoji。不替使用者捏造情緒、收穫與成就，不將規劃當成果，不暗示未晉級或較少收藏代表失敗。不為文學效果隱去錯誤與危險操作後果。
