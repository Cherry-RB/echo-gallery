# Echo Gallery UI 文案規範

## 產品敘事

Echo Gallery 是個人化內容回流工具。以「安靜的冒險日誌 × 私人的創作基地 × 成果展覽館」為語言基調，讓收藏、探索、創作與已完成的成果有可回望的來歷。系統提供線索與選擇，不以收藏量、完成率或晉級速度評價使用者。

採用繁體中文，語調沉著、內斂、略帶神祕。敘事放在副標、引導與空狀態；操作名稱、資料定義與錯誤保持精確。使用現代中文，不仿寫特定作品台詞。

## 產品命名

| 空間 | 內容物件 | 舊稱（僅供辨識歷史文件） |
| --- | --- | --- |
| 創作台 | 作品 | 爛紙頭、爛紙間 |
| 展覽館 | 展品 | 奇珍展覽館、奇珍 |

作品與展品是不同領域物件，不可混用。作品不必入藏；展品是已完成的重要成果，可包含軟體專案、閱讀成果、藝術作品與技術成果，不限於創作台的作品。入藏不代表公開展示，也不要求參與試煉；通過試煉不保證取得收益。

總覽、今日回流、全部卡片、實驗場、標籤管理、卡片查詢、卡片、實驗主題、探索紀錄、探索線、作品、試法、發現、試煉、晉級、收益及石／銅／銀／金級維持原名。命名只作用於 UI 固定文字（含 aria-label），不批次修改使用者資料；`Work`、`Treasure`、`treasureId`、路由與 API 識別字維持原狀。

## 五層文字

| 層級 | 使用位置 | 原則與例子 |
| --- | --- | --- |
| 1 | 導航、按鈕、欄位、搜尋與篩選、狀態、無障礙操作名稱 | 低敘事；短而清楚，保留「今日回流」「建立作品」「記錄收益」「儲存」「取消」「永久刪除」等功能名稱，不以比喻取代動作 |
| 2 | 頁面、區塊標題 | 簡潔且能辨認用途，如「尚未落幕的探索」「下一次相遇的間隔」；表單區塊使用具體名稱 |
| 3 | 副標、引導、表單輔助說明、較長 placeholder | 中敘事；通常一至兩句，描寫目前情境與未來可能，仍須說清楚用途 |
| 4 | 首次空狀態、完成與入藏等階段轉換 | 可有較強氛圍，依「當前情境 → 尚未展開的可能 → 可選行動」表達；成功通知只描述已確認的結果，保持簡短 |
| 5 | 統計定義、錯誤、危險操作、未儲存、同步與草稿復原 | 極低敘事；保留數值、單位、條件、後果與影響範圍，不以文學語言包裝風險 |

## 各功能語彙

| 功能區 | 建議語言 | 邊界 |
| --- | --- | --- |
| 今日回流 | 故物重逢、再次閱讀、重新理解 | 日期、回流天數、暫停、封存與待整理狀態明確顯示，不暗示使用者完全控制每次出現時間 |
| 全部卡片 | 收集、保存、翻閱、重新發現 | 收藏可以只是收藏，不暗示每張卡片都必須成為探索、作品或展品；檢視、排序與數量保持精確 |
| 實驗場 | 實驗目的、當前試法、探索紀錄、探索線、材料與線索、階段性結論 | 試法與發現分開表達；探索線用來整理方向，不要求每個實驗或每條探索線都引用卡片 |
| 創作台 | 動手製作、粗糙初稿、反覆打磨、持續練習、逐漸成形 | 包容未完成與已完成作品；不暗示版本歷史、練習統計或技藝評分；內建編輯與外部工具的能力依實作說明 |
| 展覽館 | 已完成成果、珍藏、來歷、試煉、後續價值 | 展品是已完成成果；試煉用目標等級顯示；收益限已發生的新作品、回應或機會，不限金錢收入 |
| 議事廳 | 線索、訊號、判斷、選擇、等待 | 保留系統問題、模型、迴路與介入等既有專門概念 |
| 總覽 | 此刻、尚未結束、留下、接續、可選的下一步 | 呈現現況，不寫成每日必做清單，不預設使用者需要採取行動 |
| 近期回顧 | 過往痕跡、重新發現、積累、變化 | 敘事名稱不改變統計口徑；提供原有定義、數量單位與時間範圍 |
| 回流狀態、搜尋、篩選 | 低敘事濃度，以資料說明為主 | 不用敘事詞取代查詢條件、狀態或數量 |

「產出」不做全站取代。展品記錄已發生收益的按鈕使用「＋記收益」；其他創作成果依原語意保留。「試煉」是展品檢定的介面名稱，API、型別與狀態識別字不改。

## 頁面與元件範例

| 情境 | 文案 |
| --- | --- |
| 總覽內「現在行動」副標 | 有些探索尚未結束，有些作品仍在打磨。看看此刻留下的線索，再決定要接續哪一件事。 |
| 試法尚未設定 | 新的試法尚未寫下。不妨先翻翻收集的材料。 |
| 創作台無作品 | 桌面還空著。不必等到構想完整，第一份粗糙的草稿，也足以成為開始。 |
| 展覽館無館藏 | 展櫃仍然空著。當你完成第一件值得珍藏的成果，這裡便會有它的位置。 |
| 試煉等待確認 | 試煉已經展開，結果仍未揭曉。 |
| 試煉未通過 | 這次試煉未能晉級，但經歷已經留下。 |
| 無收益紀錄 | 它已經入藏。至於未來還能帶來什麼，現在尚無答案。 |
| 載入失敗 | 無法載入卡片；提供「重新載入」操作 |
| 刪除收益紀錄 | 刪除這筆收益紀錄？刪除後無法復原；相關卡片仍會保留。 |

## 精確性與實作規則

- 區分現在狀態、未來規劃、已發生事件。API 成功回應之前，不宣稱儲存、入藏、晉級或收益記錄成功；更新既有紀錄不宣稱取得新收益。
- 首次空白、搜尋無結果、篩選無結果、已封存列表為空、載入中、載入失敗、權限不足、尚未儲存及操作成功／失敗分別描述，不共用首次引導旁白。只知道目前篩選範圍為空時，不宣稱使用者從未開始探索。不同試煉狀態的提示互斥；未來階級的預先規劃不冒充目前試煉。
- 統計保留實際數值、單位與解釋。例如「故物重逢」仍指舊卡重新參與，「展品再現價值」計算有收益紀錄的不同展品件數。
- 刪除確認說明不可復原性、將刪除的資料與仍保留的內容；封存、暫停與解除關聯不可描述成刪除本體。
- 表單必填、長度限制、網址格式、日期與錯誤以實際規則為準。Tooltip 解釋條件，不加入旁白。
- 不改動使用者自訂標題、內文、試法、發現、展品、檢定名稱或收益紀錄。範例必須標明「例如」並保持通用，不將個人主題寫成固定功能。
- 沿用局部 template 與既有共用文字來源（如 `utils/treasure.ts`、`utils/cardTextFieldCopy.ts`）。只有真正重複且需要一致維護的文字才抽共用常數，不導入額外 i18n 框架。
- Element Plus 使用套件內建繁體中文語系，涵蓋日期、分頁、預設選擇提示與關閉操作。
- 不因改字調整 API key、路徑、Query Key、Enum、Test ID、資料模型、演算法或版型。若顯示字串被用於判斷，先檢查該依賴。
- 長文優先精簡；保留既有設計系統。檢查 1440px、768px、390px、320px 下的換行、截斷、Dialog 捲動、按鈕與 Tooltip。

## 禁止事項

不使用宮廷稱謂、全面文言、成功學口號、大量驚嘆號或 Emoji。不替使用者捏造情緒、收穫與成就，不將規劃當成果，不暗示未晉級或較少收藏代表失敗。不為文學效果隱去錯誤與危險操作後果。

不反覆堆砌「命運」「宿命」「傳奇」「神諭」「靈魂」「遠征」「啟示」「篇章」「旅途」「餘響」「轉機」。這些詞只有在具體情境需要時使用，不以「新的篇章正等待你」等空泛句型填滿各頁，也不把可選行動寫成必做任務。

## 新增與修改文案的判斷

1. 先確認實際用途、顯示條件、資料範圍與操作後果，再選敘事濃度。
2. 分為「保留」「精修」「重寫」「僅修正名稱」「不可敘事化」。原文清楚且自然就保留；名稱過期只同步名稱，不追求修改量。
3. 檢查是否捏造歷史或情緒、把未知寫成答案、暗示不存在的功能、把私人入藏寫成公開展示，或將晉級與收益誤連為必然結果。
4. 以相鄰畫面檢查重複修辭，優先具體情境與短句。最後核對條件分支、無障礙名稱、相關測試與窄螢幕換行。
